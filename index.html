Crear cerebro

Genera el génesis, tu llave de firma (owner) y la llave de cifrado AES-256. Todo el contenido viaja y se guarda cifrado — sin el enlace secreto nadie puede leer ni encontrar tu red.

Conectar con enlace secreto

Pega el enlace o código que compartió el owner (contiene la llave de cifrado). Este dispositivo replica, verifica y descifra — solo lectura.

El owner decide si este dispositivo puede recordar: un enlace de invitado es siempre efímero (al cerrar la pestaña se olvida todo, nada toca el disco).
